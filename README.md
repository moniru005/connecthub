# Project Title: CONNECT HUB

CONNECT HUB is a social media platform designed to connect people and foster meaningful interactions. With a focus on simplicity, usability, and customization, CONNECT HUB aims to provide users with a seamless social networking experience.

## Technologies Used

CONNECT HUB leverages the following technologies:
- **Tailwind CSS:** Utility-first CSS framework for rapid UI development.
- **Daisy UI:** Beautiful and accessible UI components built on top of Tailwind CSS.
- **Headless UI:** Fully accessible, ready-to-use UI components for React.
- **React:** JavaScript library for building user interfaces.
- **Next.js:** React framework for server-rendered applications.
- **Node.js:** JavaScript runtime built on Chrome's V8 JavaScript engine.
- **MongoDB:** NoSQL database for storing user data and content.

## Run Locally

To get started with CONNECT HUB locally, follow these steps:
1. Clone this repository to your local machine.
2. Install the required dependencies using `npm install`.
3. Set up your MongoDB database and configure the connection in the project.
4. Start the development server using `npm run dev`.
5. Access CONNECT HUB in your browser at [Connect Hub Local](https://connecthub-1.netlify.app).

## Project Features

CONNECT HUB offers the following features:

- **User Registration and Authentication:** Users can sign up with their email or social media accounts, and choose between password-based authentication or Firebase.
- **User Profile Creation and Editing:** Users can create and personalize their profiles with details such as name, profile picture, bio, interests, and contact information. Profile information can be edited and updated at any time.
- **Post Creation and Management:** Users can create posts that include text, images, videos, and links, and have the ability to edit or delete their own posts.
- **Post Interactions:** Users can like or favorite posts, and share them with other users or on external platforms.
- **Comments and Replies:** Users can comment on posts and reply to comments, facilitating discussions and threaded conversations.
- **News Feed:** A personalized news feed displays posts from users that a person follows or interacts with, sorted chronologically or based on relevance.
- **Notifications:** Users receive notifications about activities such as likes, comments, mentions, or new followers, with customizable notification settings.
- **Privacy Settings:** Users can control the visibility of their profile and posts, choosing between public, private, or restricted visibility settings. Granular control over who can view, comment on, or interact with their content is also available.
- **Analytics and Insights:** Users can access insights into their activity on the platform, including metrics such as post engagement, follower growth, and audience demographics. Analytics tools help users understand their reach and impact.
